# shelf-bridge icon ("Queue")

The slanted planes of the folded S step forward three times: jobs in line. The slope (0.457) and the plane thickness match the Shelf mark. The front plane is Vermilion `#E8412C`, the ones behind `#C2331F` and `#8A2A1B`. The tile is ink `#1A1715` on the macOS grid (824 square, corner 185).

- `bridge-app-icon-1024.svg`: the AppIcon source for `ShelfBridge.app`. The 16, 32, 128, 256 and 512 pt PNGs at @1x and @2x are made from it (`scripts/make-app-icon.swift`).
- `bridge-mark.svg`: the mark without the tile (README, Homebrew, docs).
