# Contributing

## Build and test

Requirements: macOS 14 or later, the Swift 6 toolchain (Xcode 16), and `tmux` for the integration
tests (`Package.swift:1`, `:6`, `Tests/ShelfRunnerCoreTests/Support.swift:23-25`).

```sh
swift build                    # debug build of the CLI and the core library
swift test                     # all tests; a fake agent stands in for claude and codex
scripts/build-app.sh           # build/ShelfRunner.app (ad-hoc signed by default)
scripts/install-agent.sh       # load the LaunchAgent for that build; --uninstall removes it
e2e/sandbox-probe/run.sh       # a sandboxed app pings, reads the status, sends pause/resume
```

- Tests never run a real agent: `Tests/Fixtures/fake-agent.sh` replaces it
  (`Tests/Fixtures/fake-agent.sh:2-3`).
- `SHOW_AGENT_ERR=1 swift test` prints the agent's stderr from the integration tests
  (`Tests/ShelfRunnerCoreTests/AgentIntegrationTests.swift:39-40`).
- `scripts/release.sh` refuses a dirty working tree and runs `swift test` first
  (`scripts/release.sh:20`, `:23`).

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for how the code fits together.

## Protocol fixtures

`fixtures/protocol/v1/` is generated by `Tests/ShelfRunnerCoreTests/ProtocolFixtureTests.swift`
and checked byte for byte by every `swift test`
(`Tests/ShelfRunnerCoreTests/ProtocolFixtureTests.swift:6-8`, `:369-378`).

- Never edit those files by hand, the fixture `README.md` included. Edit the test, then run:

  ```sh
  REGEN_PROTOCOL_FIXTURES=1 swift test --filter ProtocolFixture
  ```

- If the regenerated files differ, you changed the protocol. Decide the version first, following
  [docs/protocol/README.md](docs/protocol/README.md#version-policy), and update
  [docs/protocol/v1.md](docs/protocol/v1.md) (or write the next version's document) in the same
  change.

## Rules every change keeps

- **No permission bypass flags.** No template may contain one, and `PermissionGuard` refuses to
  start if one appears (`Sources/ShelfRunnerCore/AgentCommand.swift:64-82`); tests scan the
  templates (`Tests/ShelfRunnerCoreTests/PermissionGuardTests.swift:14`, `:53`). Do not add a setting
  that turns one on.
- **No shell for task text.** Processes start with an argv array through `posix_spawn`; the task
  text is one argument and never reaches `sh -c` (`Sources/ShelfRunnerCore/Tmux.swift:3-43`,
  `Sources/ShelfRunnerCore/AgentCommand.swift:3-4`).
- **The runner never writes queue files** or anything else in your folders; it writes only the
  places in `Paths` (`Sources/ShelfRunnerCore/Paths.swift:3-4`).
- **Every line is gated**: signature, paths, approval. That is not a setting
  (`Sources/ShelfRunnerCore/Agent.swift:123-125`, `Sources/ShelfRunnerCore/Security.swift:111-131`).
- **Docs and code comments in English.** Plain words, short sentences, no em dash character.
